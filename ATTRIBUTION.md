# Attribution

This project is a fork of the web [mapcn](https://github.com/AnmolSaini16/mapcn) component library.

## Upstream project

- **Name**: mapcn
- **Author**: [Anmoldeep Singh](https://github.com/AnmolSaini16)
- **Repository**: https://github.com/AnmolSaini16/mapcn
- **Website**: https://mapcn.dev
- **License**: MIT

The original mapcn project provides ready-to-use, customizable map components for React on the web, built with MapLibre GL JS, Tailwind CSS, and shadcn/ui.

## This fork

- **Name**: mapcn-react-native
- **Repository**: https://github.com/unkn0wndfbx/mapcn-react-native
- **Maintainer**: [unkn0wndfbx](https://github.com/unkn0wndfbx)
- **License**: MIT

This fork adapts mapcn for React Native and Expo using `@maplibre/maplibre-react-native` and NativeWind. Component APIs, design tokens, and registry structure are derived from the upstream project.

## Third-party dependencies

- [MapLibre](https://maplibre.org/) — map rendering
- [MapLibre React Native](https://github.com/maplibre/maplibre-react-native) — native map bindings
- [NativeWind](https://www.nativewind.dev/) — Tailwind-style styling for React Native
- [Expo](https://expo.dev/) — React Native tooling and runtime
- [shadcn/ui](https://ui.shadcn.com/) — component patterns and conventions (upstream inspiration)

## Basemap data

Default styles use [CARTO Basemaps](https://docs.carto.com/faqs/carto-basemaps), which are based on [OpenStreetMap](https://www.openstreetmap.org/) data. Review CARTO's licensing terms before using these basemaps in production.
